🔌 Endpoints de Integração & Model Context Protocol
Conecte Cursor, Claude Desktop, LangChain, agentes autônomos ou ferramentas CLI.
POST /v1/context
Injeção Direta de Prompt (Zero Overhead)
Retorna o contexto prefixado filtrado pelos serviços ou tags requisitados pela IA. 
curl -X POST http://127.0.0.1:8000/v1/context \
  -H "Content-Type: application/json" \
  -d '{"target_services": ["pagamentos-service"], "user_query": "Qual lib de banco?"}'
POST /v1/chat/completions
Compatível com OpenAI API
Permite apontar o Cursor, Continue.dev ou SDKs OpenAI diretamente para o servidor CAG-OKF. 
curl -X POST http://127.0.0.1:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages": [{"role": "user", "content": "Quais as regras do Redis?"}]}'
POST /v1/documents/{doc_id}/append
Mutação Autônoma para IAs
Permite que agentes anexem exceções temporárias ou notas de conformidade sem corromper o documento original. 
curl -X POST http://127.0.0.1:8000/v1/documents/WIKI-RULE-001/append \
  -H "Content-Type: application/json" \
  -d '{"section_title": "Waiver Incidente #402", "content": "Aprovado bypass temporário.", "author": "SecOps"}'
