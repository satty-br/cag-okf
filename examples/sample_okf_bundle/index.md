# Corporate Security & Architecture Standards Bundle (OKF)

This Open Knowledge Format bundle defines the approved architectural patterns,
security guardrails, and compliance requirements enforced by autonomous AI review agents.

## Included Concepts & Rules
1. `db-connection-vault`: Mandatory connection pooling and dynamic Vault secret injection in Go.
2. `api-rate-limiting`: Token bucket rate limiting standards across public microservice APIs.
3. `data-retention-gdpr`: PII masking and automated 90-day retention lifecycles for LGPD/GDPR.
4. `incident-triage`: Playbook for severity classification and automated containment actions.
